# Дорожная карта развития проекта (Roadmap) — OSS Bot

> **Текущая версия:** 0.8.5  
> **Дата обновления:** 25 сентября 2026 г.

В этом документе описаны ключевые направления развития платформы **OSS Bot**: переход от монолитного сервиса к омниканальной экосистеме с удобным мобильным рабочим местом для операторов и администраторов.

---

## Концепция и целевая аудитория

Платформа разделяет пользователей на две ключевые группы с разными инструментами:

1. **Студенты (пользователи сервиса)**:
   - Каналы: публичные боты в **VK** и **Telegram**.
   - Задачи: подача обращений в отделы, отслеживание статуса, поиск ответов в базе знаний (FAQ), запись на мероприятия.

2. **Операторы отделов и суперадминистраторы**:
   - Каналы: **Веб-панель**, **Telegram Mini App (TMA)**, нативное **Android-приложение**.
   - Задачи: мгновенная обработка входящих заявок, пуш-уведомления, мониторинг SLA, аудит системы. Обычным пользователям доступ сюда закрыт (Zero Public Attack Surface).

## Реализованные этапы

### ✅ Релиз 0.8.4 / 0.8.4.1 — Комплексная безопасность, NetBird и сквозные тесты (СЕНТЯБРЬ 2026)
- **Полная изоляция контура:** Миграция с Tailscale на NetBird VPN. Веб-панель заблокирована для публичного интернета (только подсеть `100.64.0.0/10` и локальные доверенные сети через Caddy).
- **Устранение уязвимостей:**
  - Внедрение HSTS `max-age=31536000` и безопасного экранирования CSV.
  - Защита от ReDoS и wildcard-инъекций в ILIKE поиске.
  - Лимит 3000 символов на описание тикета.
  - Строгие проверки production-паролей в `ensure_production_config()`.
  - Ротация процессов Uvicorn (`--limit-max-requests 1000`).
- **Сквозное тестирование кнопок:**
  - Написан 21 тест всех кнопок Telegram-бота.
  - Написано 9 тестов всех кнопок и форм веб-панели.
  - Общее покрытие: 63/63 успешно пройденных теста.
- **Инфографика и архитектурные схемы:**
  - Создана единая мастер-схема `Kak_rabotaet_studencheskiy_pomoschnik.svg` для Figma с простыми пояснениями для людей без IT-опыта.

### ✅ Релиз 0.8.3.x — Telegram-бот мониторинга и интеграция Mini App
- Модульный бот на `aiogram 3.x`: клавиатуры статуса, управления техработами, бэкапами и логами.

- Динамическое включение и отключение двухфакторной аутентификации (2FA).

## Ближайшие этапы реализации

### 🔄 Фаза 3: Telegram-бот для студентов (В разработке)
Запуск полнофункционального бота в Telegram параллельно с существующим VK-ботом:
- Единое ядро бизнес-логики (`core/ticket_service.py`).
- Полный аналог сценариев: создание тикетов, FAQ, подписка на события, отслеживание ответов.
- Омниканальный Outbox: ответ оператора автоматически отправляется в тот мессенджер, откуда пришёл студент.

### 📅 Фаза 4: Telegram Mini App (TMA) для операторов
Легковесное рабочее место прямо внутри Telegram без необходимости устанавливать отдельное приложение:
- Стек: React / TypeScript, Tailwind CSS, Telegram WebApp SDK.
- Открытие конкретной заявки прямо по кнопке из уведомления в Telegram-боте.
- Быстрая смена статуса в один клик и отправка шаблонов ответов.

### 📅 Фаза 5: Нативное Android-приложение для операторов
Мобильный пульт управления для дежурных операторов и суперадмина:
- Стек: Kotlin, Jetpack Compose, Clean Architecture + MVI, Retrofit 2, Room DB.
- Push-уведомления: Firebase Cloud Messaging (FCM) + RuStore Push SDK.
- Биометрия: отпечаток пальца / Face Unlock (BiometricPrompt).
- Офлайн-кэш и мгновенная отправка ответов студентам.

### 📅 Фаза 6: Real-time обновления и ИИ-автоматизация
- **WebSocket / SSE:** Живое обновление очереди заявок в веб-панели без перезагрузки страниц.
- **ИИ-классификация:** Автоматическое определение отдела и темы обращения студента с помощью нейросетевых классификаторов текста.
- **SLA-контроль:** Автоматические эскалации и напоминания, если заявка не обработана за установленное время (например, 24 часа).
