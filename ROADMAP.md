# Дорожная карта развития проекта (Roadmap)

В этом документе описаны ключевые направления развития платформы **OSS Bot**: переход от монолитного сервиса к омниканальной экосистеме с удобным мобильным рабочим местом для операторов и администраторов.

---

## Концепция и целевая аудитория

Платформа разделяет пользователей на две ключевые группы с разными инструментами:

1. **Студенты (пользователи сервиса)**:
   - Каналы: публичные боты в **VK** и **Telegram**.
   - Задачи: подача обращений в отделы, отслеживание статуса, поиск ответов в базе знаний (FAQ), запись на мероприятия.

2. **Операторы отделов и суперадминистраторы**:
   - Каналы: **Веб-панель**, нативное **Android-приложение**, **Telegram Mini App (TMA)**.
   - Задачи: мгновенная обработка входящих заявок, пуш-уведомления, мониторинг SLA, аудит системы. Обычным пользователям доступ сюда закрыт.

---

## Ключевые направления разработки

### 1. Нативное Android-приложение для операторов

Мобильный пульт управления для дежурных операторов и суперадмина без привязки к компьютеру.

- **Стек:** Kotlin, Jetpack Compose, Material Design 3, Clean Architecture + MVI, Retrofit 2, Room DB.
- **Push-уведомления:** Firebase Cloud Messaging (FCM) + RuStore Push SDK.
- **Безопасность:** Вход по логину и паролю + 2FA, биометрия (отпечаток пальца / Face Unlock через BiometricPrompt), EncryptedSharedPreferences.
- **Функции:**
  - Моментальные пуши о новых обращениях в закреплённый отдел.
  - Быстрый просмотр очереди тикетов и переписки.
  - Ответ студенту с поддержкой готовых шаблонов.
  - Смена статуса заявки, эскалация, перенаправление в другой отдел.
  - Для суперадмина: живой журнал аудита, статус здоровья сервисов и проверка синхронизации времени.

---

### 2. Telegram Mini App (TMA) для операторов

Легковесное рабочее место прямо внутри Telegram без необходимости устанавливать отдельное приложение.

- **Стек:** React / TypeScript, Vite, Tailwind CSS, Telegram WebApp SDK.
- **Безопасность:** Валидация подписи `initData` (HMAC-SHA256) на бэкенде с обязательной проверкой роли оператора.
- **Функции:**
  - Открытие конкретной заявки прямо по кнопке из уведомления в Telegram-боте.
  - Быстрая смена статуса в один клик.
  - Отправка ответа студенту.

---

### 3. Telegram-бот платформы

Запуск полнофункционального бота в Telegram параллельно с существующим VK-ботом.

- **Стек:** Python 3.12+, `aiogram 3.x`, единая бизнес-логика ядра (`core/`).
- **Функции для студентов:**
  - Полный аналог сценариев VK: создание тикетов, FAQ, подписка на события, отслеживание ответов.
- **Функции для администраторов:**
  - Мгновенные служебные уведомления о новых заявках в закреплённые отделы.
  - Напоминания о нарушении сроков ответа (SLA).
  - Инлайн-кнопка «Открыть заявку в Mini App».

---

### 4. Развитие ядра и бэкенда платформы

- **Real-time обновления (WebSocket / SSE):**
  - Живое обновление очереди заявок в веб-панели и мобильных клиентах без ручной перезагрузки страницы.
- **Расширение REST API v1:**
  - Полноценные эндпоинты аутентификации (JWT + Refresh tokens) для мобильного приложения.
  - Эндпоинты регистрации push-токенов устройств.
- **Единый омниканальный Outbox:**
  - Маршрутизация ответов в тот мессенджер, откуда студент изначально создал обращение (VK или Telegram).
