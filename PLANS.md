# Планы развития проекта: мобильное рабочее место администратора и суперадминистратора

Подробная документация планов развития находится в файле:
[docs/PLANS.md](docs/PLANS.md).

> **Целевая аудитория:**
> Мобильное приложение (Android App) и Telegram Mini App (TMA) разрабатываются **исключительно для администраторов отделов (операторов) и суперадминистраторов платформы**. Обычным студентам там делать нечего — студенты взаимодействуют с системой через привычный публичный VK-бот.

### Ключевые направления разработки:
1. **Нативное Android-приложение для операторов и суперадмина:**
   - Стек: Kotlin, Jetpack Compose, Material 3, Clean Architecture + MVI.
   - Рабочий стол оператора: очередь обращений отдела, смена статусов, отправка ответов студентам, шаблоны.
   - Пульт суперадминистратора: просмотр системного журнала аудита (Логи), управление отделами и персоналом, мониторинг синхронизации времени и здоровья сервисов.
   - Push-уведомления (FCM / RuStore) о новых поступивших заявках, вход по 2FA и биометрии (BiometricPrompt).
2. **Telegram Mini App (TMA Admin Console):**
   - Интерактивный клиент прямо внутри Telegram на React / Vite / Tailwind / Telegram UI Kit.
   - Бесшовная авторизация по initData со строгой проверкой роли (доступ закрыт для не-администраторов).
   - Быстрый приём и обработка заявок дежурным оператором со смартфона.
3. **Служебный Telegram-бот:**
   - Бот на aiogram 3 для рассылки операторам мгновенных алертов о новых заявках и эскалациях через Transactional Outbox с кнопками «Открыть в Mini App».
