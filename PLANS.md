# Планы развития проекта (Roadmap)

Подробный документ планов развития платформы и проектирования нативного мобильного приложения для Android находится в:
[docs/PLANS.md](docs/PLANS.md).

Основные направления:
1. **Мобильное приложение для Android:** нативный клиент на Kotlin + Jetpack Compose (Clean Architecture, Material 3, push-уведомления через FCM/RuStore, офлайн-режим Room DB).
2. **Расширение каналов:** подключение Telegram-бота с единым ядром обработки тикетов.
3. **Интеллектуальный ассистент:** автоподбор ответов из FAQ до отправки тикета.
4. **Аналитика:** расширенный мониторинг SLA операторов и дашборды в Grafana.
