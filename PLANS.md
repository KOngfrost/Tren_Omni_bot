# Планы развития проекта (Roadmap)

Подробный документ планов развития платформы и проектирования нативного мобильного приложения для Android находится в:
[docs/PLANS.md](docs/PLANS.md).

Основные направления:
1. **Мобильное приложение для Android:** нативный клиент на Kotlin + Jetpack Compose (Clean Architecture, Material 3, push-уведомления через FCM/RuStore, офлайн-режим Room DB).
2. **Telegram-бот на aiogram 3:** полноценный асинхронный бот с FSM-сценариями, привязкой аккаунтов и доставкой через Transactional Outbox.
3. **Telegram Mini App (TMA):** интерактивное веб-приложение прямо внутри Telegram (React/Vite/Tailwind, Telegram WebApp SDK, бесшовная аутентификация по HMAC initData, подача заявок с фото, трекер статусов и FAQ).
4. **Интеллектуальный ассистент:** автоподбор ответов из FAQ до отправки тикета.
5. **Аналитика:** расширенный мониторинг SLA операторов и дашборды в Grafana.
