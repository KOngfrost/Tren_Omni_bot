# Планы развития проекта: Мобильное рабочее место администратора и суперадминистратора

Подробная документация: [docs/PLANS.md](docs/PLANS.md).

> **Целевая аудитория:**
> Основной пользователь приложения на Android (а также Telegram Mini App) — это **администратор отдела (оператор)** и **суперадминистратор**. 
> Обычным студентам там делать нечего: студенты взаимодействуют с сервисом исключительно через публичный бот ВКонтакте.

### 1. Нативное приложение для Android
- **Стек:** Kotlin, Jetpack Compose, Material 3, Clean Architecture + MVI, Retrofit 2, Room DB, FCM / RuStore Push, BiometricPrompt (биометрия).
- **Для чего создаём:** оперативный мобильный пульт для операторов (пуши о новых заявках в отдел, быстрый ответ студенту, смена статусов) и суперадминистратора (просмотр журнала аудита/логов в реальном времени, мониторинг времени и здоровья системы).

### 2. Telegram Mini App (TMA)
- **Стек:** React, Vite, TypeScript, Tailwind CSS, Telegram WebApp SDK / UI Kit.
- **Для чего создаём:** рабочее место дежурного оператора прямо внутри Telegram. Быстрый ответ на заявку и смена статуса в один клик без установки приложения (вход строго по проверке роли админа).

### 3. Служебный Telegram-бот
- **Стек:** Python 3.12+, aiogram 3.x.
- **Для чего создаём:** мгновенная рассылка служебных алертов операторам о новых обращениях и просроченных тикетах с кнопкой перехода в Mini App.
