# Планы развития проекта: Мобильное рабочее место администратора и омниканальность

Подробная документация: [docs/PLANS.md](docs/PLANS.md).

> **Целевая аудитория:**
> - **Приложение на Android и Telegram Mini App** создаются исключительно для **администраторов отделов (операторов)** и **суперадминистраторов**. Обычным студентам там делать нечего.
> - **Боты (Telegram-бот и VK-бот)** — публичные и общие, работают как для **студентов**, так и для **администраторов**.

### 1. Нативное приложение для Android
- **Стек:** Kotlin, Jetpack Compose, Material 3, Clean Architecture + MVI, Retrofit 2, Room DB, FCM / RuStore Push, BiometricPrompt (биометрия).
- **Для чего создаём:** оперативный мобильный пульт управления для операторов (пуши о новых заявках в отдел, быстрый ответ студенту, смена статусов) и суперадминистратора (журнал аудита/логов в реальном времени, мониторинг времени и здоровья системы). Студентам доступ закрыт.

### 2. Telegram Mini App (TMA)
- **Стек:** React, Vite, TypeScript, Tailwind CSS, Telegram WebApp SDK / UI Kit.
- **Для чего создаём:** рабочее место дежурного оператора прямо внутри Telegram. Быстрый ответ на заявку и смена статуса в один клик без установки приложения (вход строго по проверке роли админа).

### 3. Telegram-бот (аналогично VK-боту)
- **Стек:** Python 3.12+, aiogram 3.x, Transactional Outbox.
- **Для чего создаём:** универсальный бот платформы для студентов и администраторов:
  - **Для студентов:** подача обращений в отделы, отслеживание статуса, FAQ, регистрация на мероприятия (как в VK-боте).
  - **Для администраторов:** мгновенные служебные алерты о новых заявках, служебные команды и кнопка перехода в Mini App.
