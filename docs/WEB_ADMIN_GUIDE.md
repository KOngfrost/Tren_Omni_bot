# Руководство веб-панели

## Вход и роли

Откройте адрес панели, выданный владельцем сервера. Сессия живёт один час и защищена `HttpOnly`, `SameSite=strict` и, при HTTPS, `Secure` cookie. После пяти неудачных попыток вход временно ограничивается.

- `SUPERADMIN` видит все отделы, управляет администраторами и передаёт заявки.
- `DEPARTMENT_ADMIN` видит и редактирует только свой отдел.

Права и отдел проверяются по актуальной записи в `web_users`, поэтому изменение роли или деактивация применяется и к уже открытой сессии.

## Заявки

В разделе «Заявки» доступны пагинация, фильтр и карточка заявки. Администратор отдела получает только заявки своего отдела. В карточке отображаются описание, статус и история.

Ответ сохраняется в истории и ставится в outbox. В VK он уйдёт после успешной доставки; при недоступности VK воркер повторит попытку. В анонимном разделе пользователь сам выбирает режим: при «Остаться анонимным» VK ID не сохраняется, а при «Остаться не анонимным» администратор сможет ответить через VK.

Допустимые переходы статусов задаются сервисом заявок. Передача в другой отдел доступна только `SUPERADMIN`.

## Контент и логи

«FAQ», «База знаний» и «События» показываются с фильтром отдела. `DEPARTMENT_ADMIN` может создать запись только в своём отделе; значение `department_id` из формы не считается доказательством права.

«Логи» доступны с пагинацией и экспортом CSV. Администратор отдела видит записи, связанные с его отделом; суперадминистратор видит полный журнал.

## Безопасность

Все изменяющие формы используют CSRF-токен. HTML очищается перед сохранением и экранируется в шаблонах. CSP использует nonce из `request.state`, а не из cookie-сессии. Ошибки сервера не показывают пользователю детали исключения.
