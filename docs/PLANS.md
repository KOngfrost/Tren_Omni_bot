# Планы развития проекта: Мобильное рабочее место администратора и омниканальность

> **Целевая аудитория:**
> - **Приложение на Android и Telegram Mini App** разрабатываются исключительно для **администраторов отделов (операторов)** и **суперадминистраторов платформы**. Обычным студентам там делать нечего: доступ строго ограничен.
> - **Боты платформы (Telegram-бот и VK-бот)** — публичные и универсальные, работают как для **студентов**, так и для **администраторов**.

---

## 1. Нативное приложение для Android

- **Стек технологий:**
  - **Язык и UI:** Kotlin, Jetpack Compose, Material Design 3.
  - **Архитектура:** Clean Architecture + MVI.
  - **Сеть и данные:** Retrofit 2, OkHttp 4, kotlinx.serialization, Room DB (локальный кэш).
  - **Уведомления:** Firebase Cloud Messaging (FCM) + RuStore Push SDK.
  - **Безопасность:** Вход по паролю + 2FA, биометрия (BiometricPrompt: отпечаток пальца / Face Unlock), EncryptedSharedPreferences.

- **Для чего создаём:**
  Мобильный пульт управления для операторов и суперадминов, позволяющий оперативно работать со смартфона без привязки к ПК:
  - **Для администратора отдела (оператора):** моментальные push-уведомления о новых обращениях в отдел, быстрый просмотр очереди заявок, оперативные ответы студентам с использованием готовых шаблонов, переключение статусов и эскалация. Студентам доступ закрыт.
  - **Для суперадминистратора:** мобильный доступ к журналу аудита (системным логам) в реальном времени, мониторинг доступности и синхронизации времени сервисов, сквозной контроль обращений по всем отделам.

---

## 2. Telegram Mini App (TMA)

- **Стек технологий:**
  - React, Vite, TypeScript, Tailwind CSS, Telegram WebApp SDK / Telegram UI Kit.
  - Авторизация и безопасность: валидация `initData` (HMAC-SHA256) на бэкенде со строгой проверкой роли (не-администраторам вход закрыт).

- **Для чего создаём:**
  Легковесный интерфейс дежурного оператора прямо внутри мессенджера Telegram без необходимости установки отдельного приложения. Дежурный администратор переходит в заявку из уведомления бота в одно касание, меняет статус и отправляет ответ студенту.

---

## 3. Telegram-бот платформы (аналогично VK-боту)

- **Стек технологий:**
  - Python 3.12+, aiogram 3.x, интеграция с Transactional Outbox бэкенда.

- **Для чего создаём:**
  Полноценный омниканальный бот для студентов и администраторов по аналогии с ботом ВКонтакте:
  - **Для студентов:** подача обращений в отделы СУБД, отслеживание статуса рассмотрения, поиск по FAQ и базе знаний, запись на студенческие мероприятия.
  - **Для администраторов:** приём мгновенных служебных уведомлений о поступивших заявках, напоминания о нарушении сроков ответа (SLA), служебные команды и прямая кнопка «Открыть заявку в Mini App».
