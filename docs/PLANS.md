# Планы развития проекта и разработка мобильного приложения для Android

Данный документ описывает стратегию развития платформы студенческого бота, архитектуру и пошаговый план создания нативного мобильного приложения для операционной системы **Android**, а также расширение бэкенда и смежных сервисов.

---

## 1. Концепция и цели мобильного приложения

Платформа уже включает в себя VK-бота для студентов и административную веб-панель. Нативное мобильное приложение для Android призвано расширить охват аудитории, повысить удобство взаимодействия и обеспечить оперативное информирование через push-уведомления.

### Ключевые роли в приложении:
1. **Студент (Основной пользователь):**
   - Быстрая подача обращений в профильные отделы с прикреплением медиафайлов (фотографий, документов).
   - Интерактивный трекер статуса обращений в реальном времени.
   - Мгновенные push-уведомления о смене статуса или получении ответа от оператора.
   - Полнотекстовый поиск по FAQ и базе знаний с офлайн-доступом.
   - Афиша студенческих мероприятий с записью в один клик.
   - Управление профилем (ФИО, общежитие/комната, контактные данные).
2. **Администратор / Оператор отдела:**
   - Мобильный пульт оператора для оперативного ответа на обращения на ходу.
   - Уведомления о новых срочных заявках.
   - Быстрая смена статусов, эскалация и передача в администрацию или студсовет.

## 2. Архитектура и стек технологий Android-приложения

Приложение строится на базе современных стандартов Android-разработки (Modern Android Development — MAD), рекомендаций Google и принципов чистой архитектуры (Clean Architecture).

`
                      ┌────────────────────────────────────────┐
                      │          UI / Presentation Layer       │
                      │  (Jetpack Compose + Material 3 + MVI)  │
                      └───────────────────┬────────────────────┘
                                          │
                      ┌───────────────────▼────────────────────┐
                      │              Domain Layer              │
                      │       (UseCases + Business Models)     │
                      └───────────────────┬────────────────────┘
                                          │
                      ┌───────────────────▼────────────────────┐
                      │               Data Layer               │
                      │ (Repository Pattern, DTOs, Mappers)    │
                      └─────────┬────────────────────┬─────────┘
                                │                    │
              ┌─────────────────▼──────┐      ┌──────▼─────────────────┐
              │      Network Source    │      │      Local Source      │
              │ (Retrofit2 / OkHttp3 / │      │  (Room DB + DataStore  │
              │ Kotlinx Serialization) │      │      EncryptedPrefs)   │
              └────────────────────────┘      └────────────────────────┘
`

### 2.1. Технологический стек:
- **Язык разработки:** Kotlin (последняя стабильная версия, Coroutines + Flow).
- **Пользовательский интерфейс (UI):** Jetpack Compose, Material Design 3, Compose Navigation.
- **Архитектура:** Clean Architecture + MVI (Model-View-Intent) / MVVM с реактивными состояниями StateFlow и однонаправленным потоком данных (UDF).
- **Внедрение зависимостей (DI):** Google Hilt / Koin.
- **Сетевое взаимодействие:** Retrofit 2 + OkHttp 4 (с поддержкой переподключений, логирования и перехватчиков токенов).
- **Сериализация:** kotlinx.serialization.
- **Локальная база данных (офлайн-кеш):** Room Database + SQLite.
- **Хранение настроек и токенов:** Jetpack DataStore + AndroidX Security (EncryptedSharedPreferences).
- **Безопасность и биометрия:** AndroidX Biometric (вход по отпечатку пальца / Face Unlock).
- **Push-уведомления:** Двойной провайдер:
  - **Firebase Cloud Messaging (FCM)** — для устройств с Google Play Services.
  - **RuStore Push SDK** — для устройств без сервисов Google (Huawei, Honor и др.) и распространения через RuStore.
- **Тестирование:** JUnit 5, MockK, Turbine (тестирование Flow), Compose UI Test.

## 3. Взаимодействие с существующим бэкендом (FastAPI REST API)

Бэкенд проекта уже предоставляет основу REST API (web/routes/api_v1.py и web/routes/api.py). В рамках интеграции мобильного приложения контракты расширяются следующими эндпоинтами:

| Метод | Эндпоинт | Описание | Роль |
|---|---|---|---|
| POST | /api/v1/auth/mobile/login | Авторизация через VK ID SDK или связку логин/пароль | Все |
| POST | /api/v1/auth/mobile/refresh | Обновление пары JWT (Access / Refresh токены) | Все |
| GET | /api/v1/tickets | Получение списка обращений с пагинацией и фильтром по статусам | Студент / Оператор |
| POST | /api/v1/tickets | Создание нового обращения (включая multipart загрузку вложений) | Студент |
| GET | /api/v1/tickets/{id} | Детальная информация по обращению и история переписки | Студент / Оператор |
| PATCH | /api/v1/tickets/{id}/status | Смена статуса заявки и назначение исполнителя | Оператор |
| POST | /api/v1/tickets/{id}/reply | Отправка ответа студенту | Оператор |
| GET | /api/v1/faq | Список вопросов и ответов с группировкой по отделам | Студент |
| GET | /api/v1/knowledge-base | Статьи и справочные материалы базы знаний | Студент |
| GET | /api/v1/events | Список активных студенческих мероприятий | Студент |
| POST | /api/v1/events/{id}/register | Запись на мероприятие | Студент |
| POST | /api/v1/devices/register-push | Регистрация токена устройства (FCM / RuStore) для отправки пушей | Все |

## 5. Разработка Telegram-бота (Telegram Bot)

Telegram является одним из наиболее востребованных каналов коммуникации среди студентов. Реализация Telegram-бота позволит расширить омниканальность сервиса при сохранении единого ядра обработки данных.

### 5.1. Архитектура и стек технологий:
- **Фреймворк:** Python 3.12+, **aiogram 3.x** (высокопроизводительный асинхронный фреймворк с полной поддержкой современных методов Telegram Bot API).
- **Паттерн интеграции:** ядро бизнес-логики полностью переиспользуется из core/ticket_service.py. Никакого дублирования кода работы с базой данных.
- **Модель пользователей:** в таблице users поле 	elegram_id: BigInteger связывается с профилем студента. Если студент уже зарегистрирован в VK, поддерживается связывание аккаунтов.
- **Надёжная доставка сообщений (Outbox):**
  - Использование паттерна Transactional Outbox (таблица 	elegram_outbox), гарантирующего доставку уведомлений студентам об ответах операторов и смене статусов даже при сетевых сбоях Telegram API.
- **FSM и навигация:** Aiogram FSM (MemoryStorage / RedisStorage) для пошагового создания обращения (выбор отдела, темы, описания и медиафайлов).

### 5.2. Команды и функционал бота:
- /start — приветствие, определение роли и главное меню.
- /new — мастер создания нового обращения.
- /tickets — просмотр списка активных и завершённых заявок с историей переписки.
- /faq — доступ к базе знаний и часто задаваемым вопросам.
- /events — афиша мероприятий и регистрация.
- /app — запуск Telegram Mini App в один клик.

## 6. Разработка Telegram Mini App (TMA)

Telegram Mini App (TMA) предоставит студентам полноценный, плавный и богатый графический интерфейс прямо внутри Telegram, устраняя ограничения текстового бота.

`
                      ┌────────────────────────────────────────┐
                      │          Telegram Mini App (SPA)       │
                      │  (React / Vite / Tailwind / TWA SDK)   │
                      └───────────────────┬────────────────────┘
                                          │  HTTPS + InitData
                                          │  (HMAC-SHA256 Auth)
                      ┌───────────────────▼────────────────────┐
                      │        FastAPI REST API (/api/v1)      │
                      │    (Валидация InitData + JWT Сессия)   │
                      └───────────────────┬────────────────────┘
                                          │
                      ┌───────────────────▼────────────────────┐
                      │           Core & PostgreSQL 16         │
                      │ (TicketService, Outbox, Redis, Models) │
                      └────────────────────────────────────────┘
`

### 6.1. Стек технологий фронтенда:
- **Стек:** React 18 / Vue 3, Vite, TypeScript, Tailwind CSS.
- **UI-библиотека:** Telegram UI (компоненты, визуально неотличимые от нативных элементов iOS и Android в Telegram).
- **Интеграция с Telegram WebApp SDK:**
  - initData для безопасной бесшовной авторизации без ввода логина и пароля.
  - Тактильный виброотклик (HapticFeedback) при переключении табов, отправке формы и выборе статусов.
  - Нативная кнопка MainButton для подтверждения действий и BackButton для навигации.
  - Автоматическая адаптация под тему Telegram (светлая/тёмная, акцентные цвета клиента).
  - Полноэкранный режим и блокировка случайного закрытия свайпом вниз при заполнении форм (enableClosingConfirmation).

### 6.2. Безопасность и авторизация:
1. При открытии Mini App клиент передаёт строку Telegram.WebApp.initData.
2. Бэкенд на FastAPI валидирует криптографическую подпись через HMAC-SHA256 с использованием токена Telegram-бота (hash_hmac).
3. При успешной валидации проверяется или создаётся пользователь в БД, после чего выдаётся кратковременный JWT-токен для обращения к /api/v1/.

### 6.3. Экраны и сценарии Mini App:
1. **Главная (Дашборд студента):**
   - Быстрый статус активных обращений.
   - Баннеры ближайших мероприятий.
   - Поисковая строка по FAQ.
2. **Создание обращения:**
   - Выбор отдела из каталога с иконками и описанием обязанностей.
   - Ввод темы и описания с автоподбором похожих решений из FAQ.
   - Загрузка фотографий прямо из галереи телефона.
   - Тумблер анонимной подачи.
3. **Мои заявки (Трекер статусов):**
   - Интерактивный таймлайн движения заявки (Новое -> В обработке -> Передано -> Выполнено).
   - Чат переписки с оператором отдела.
4. **FAQ и База знаний:**
   - Мгновенный поиск по ключевым словам.
   - Интерактивные спойлеры с готовыми ответами.
5. **Афиша событий:**
   - Карточки мероприятий с расписанием и кнопкой записи в 1 клик.

## 8. Перспективное видение омниканальной платформы

В результате реализации платформа объединит 4 интерфейса взаимодействия вокруг единого ядра:
1. **VK-бот:** проверенный временем канал для пользователей ВКонтакте.
2. **Telegram-бот + Mini App:** современный интерактивный веб-клиент прямо в Telegram.
3. **Нативное Android-приложение:** максимальная производительность, push-уведомления и офлайн-режим.
4. **Административная веб-панель:** единый командный центр для операторов отделов и суперадминистраторов.
